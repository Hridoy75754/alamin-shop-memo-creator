# আলামিন কম্পিউটার এন্ড সার্ভিসিং সেন্টার

## GitHub Pages-এ প্রকাশ
1. GitHub-এ নতুন **Public** repository তৈরি করুন, যেমন `shop-memo-creator`.
2. `Add file` → `Upload files` নির্বাচন করে `index.html` আপলোড করুন এবং **Commit changes** চাপুন।
3. Repository → **Settings** → **Pages** খুলুন।
4. **Build and deployment** অংশে **Deploy from a branch** নির্বাচন করুন।
5. Branch: `main`, folder: `/(root)` নির্বাচন করে **Save** করুন।
6. কয়েক মিনিট পর Pages পেজে প্রকাশিত ওয়েবসাইটের URL দেখাবে।

## ব্যবহার
- `নতুন মেমো` থেকে আইটেম যোগ করে দাম/পরিমাণ দিন, তারপর **মেমো সংরক্ষণ** চাপুন।
- A4 বা ছোট রসিদ প্রিন্ট বেছে নিয়ে প্রিন্ট ডায়ালগে PDF হিসেবে Save করা যায়।
- `পণ্য ও দাম` থেকে পণ্য আগে যোগ করলে মেমোতে নাম বাছলে দাম স্বয়ংক্রিয়ভাবে বসে।
- `বিক্রির হিসাব`-এ তারিখ বেছে দৈনিক রিপোর্ট দেখুন এবং CSV ডাউনলোড করুন।
- `ডেটা ব্যাকআপ ডাউনলোড` দিয়ে JSON ব্যাকআপ নিয়মিত সংরক্ষণ করুন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এই সংস্করণে মেমো ও পণ্য একই ব্রাউজারের Local Storage-এ থাকে। অন্য ডিভাইসে স্বয়ংক্রিয়ভাবে সিঙ্ক হয় না। ব্রাউজারের সাইট ডেটা মুছে গেলে তথ্য হারাতে পারে। JSON ব্যাকআপ নিয়মিত নিন। GitHub Pages-এ কোড পাবলিক হতে পারে, তাই কাস্টমারের গোপন তথ্য কোডের মধ্যে লিখবেন না।
